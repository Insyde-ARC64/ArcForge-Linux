# ArcForge Linux
__________________________________________________________________
A full-fledged linux distribtuion developed to inject a new life in old PCs and Laptops having issues with modern applications and their support and also inability to run modern Operating Systems.

Built with Debian GNU/Linux 13.6 Trixie as the base system amd64/x64/x86_64 (64-bit) variant.

# Important notice
ArcForge Linux needs a CPU with x86-64/x64/amd64 (64-bit) architecture to run. It would neither run on ARM chips (example: armv7a, armv8, armv9, RISC, etc.) nor on a i386/i586/i686 (32-bit) CPU..

# !!!! The default username for live system is 'user' and the password is 'live'.!!!!!!

# Requirements: -FOR INSTALLED SYSTEM
~> A x64/x86_64/amd64 (64-bit) Intel/AMD CPU with a minimum 1 core 1 thread. A CPU with 2 cores is recommended for smooth experience.
~> A minimum of 1 GiB DDR2 RAM. Recommended RAM size is 2 GiB.
~> A minimum of 12 GiB Storage. 16 GiB is recommended.

# Requirements: -FOR LIVE SYSTEM(with no persistence)
~> Minimum 2 GiB RAM.
~> Minimum 8 GiB of USB 2.0 stick.
~> A x64/x86_64/amd64 (64-bit) Intel/AMD CPU with a minimum 1 core 1 thread. A CPU with 2 cores is recommended for smooth experience.

# Requirements: -FOR LIVE SYSTEM(with persistence)
~> Minimum 2 GiB RAM.
~> Minimum 16 GiB of USB 2.0 stick.
~> A x64/x86_64/amd64 (64-bit) Intel/AMD CPU with a minimum 1 core 1 thread. A CPU with 2 cores is recommended for smooth experience.
